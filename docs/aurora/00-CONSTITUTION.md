# AURORA
## Constitution v1.0

> Aurora is the operating system for VouchEdge.

---

# Mission

Build the highest quality sports intelligence platform in the world.

Aurora exists to create confidence through evidence.

Users should never wonder:

- What happened?
- Why?
- Can I trust this?
- What should I do next?

Every interface must answer those questions.

---

# Vision

We are not building another betting website.

We are building professional decision software.

Aurora should feel closer to Bloomberg, TradingView, Linear and Apple than any sportsbook.

---

# Core Principles

1. Evidence before decoration.
2. Typography before graphics.
3. Motion has purpose.
4. Every pixel earns its place.
5. Every component answers a question.
6. Clarity beats cleverness.
7. Premium is felt, not added.
8. Design for experts. Welcome beginners.
9. Consistency over novelty.
10. Build systems, not screens.

---

# Engineering Principles

- Single responsibility.
- Composition over duplication.
- Strong typing everywhere.
- Canonical data flow.
- One source of truth.
- Predictable architecture.
- Test critical paths.
- Mobile-first.
- Performance by default.

---

# Design Principles

Every screen should communicate:

1. Situation
2. Evidence
3. Confidence
4. Decision
5. Action

If one is missing, the design is incomplete.

---

# Component Philosophy

Aurora does not have "cards."

Aurora has:

- Surface
- Verdict
- Evidence
- Signal
- Judge
- Timeline
- Pressure
- Radar
- Console
- Beacon

Every component has a single responsibility.

---

# Motion

Motion exists to:

- explain
- guide
- reinforce

Never decorate.

---

# Color

Color communicates meaning.

Never aesthetics.

---

# Typography

Typography is the primary hierarchy system.

Spacing is the secondary hierarchy system.

Borders are the last resort.

---

# Anti-Patterns

Forbidden:

- Generic dashboards
- Meaningless gradients
- Decorative animations
- Fake glass
- UI copied from competitors
- Duplicate components
- Magic numbers
- Business logic inside presentation components

---

# Quality Gate

Nothing ships unless it is:

- Useful
- Fast
- Accessible
- Testable
- Consistent
- Mobile-first
- Premium

---

# AI Constitution

Every AI working on VouchEdge must:

1. Read this document first.
2. Respect existing architecture.
3. Explain architectural impact.
4. Reuse before creating.
5. Never introduce design debt.
6. Leave the project better than it was found.

---

# Living Document

This Constitution evolves.

Principles evolve slowly.

Implementation evolves continuously.

Aurora is the permanent source of truth.
